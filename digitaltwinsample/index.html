THE PROCESS

從資料到驗證，逐步建立

01

抽取既有特徵

從臺灣問卷取用人口背景、政府信任、核能安全態度與核廢料知識；目標題為是否同意在居住鄉鎮市區設置核廢料貯存場。

  • 居住地、性別、年齡、教育、職業、收入
  • 核廢料管理信心、核能安全態度、相關知識
02

建立可控 persona

把每位真人受訪者的既有欄位寫成結構化描述。模型只能依這些已給定資訊判斷，不能自行補入政治立場、家庭背景或未驗證的地理常識。

03

獨立呼叫本地 LLM

以 Ollama 對每一個 persona 建立新的 messages context；不保留前一個人、也不保留前一次的生成紀錄，避免跨個體污染。

Persona i → new context → LLM → Ŷᵢ
04

強制結構化輸出

模型僅能輸出四級量尺選項、信心與簡短理由；以 JSON Schema 與答案驗證降低解析失敗，並保留原始輸出供稽核。

非常不同意不太同意還算同意非常同意
05

重複模擬，而非只跑一次

每位受訪者在相同設定下重複 10 次，溫度 0.7、沒有固定 seed。15 位受訪者 × 10 次 = 150 次模擬，用以分離隨機波動與模型的穩定偏向。

06

與真人答案驗證

比較逐次命中率、persona 眾數命中、MAE、±1 類別正確率、Spearman 相關，以及整體答案分布。可靠度與效度必須分開看。

研究訊號

READ THE RESULTS CAREFULLY

高穩定，不等於高效度

TAIDE 的重複結果顯示每位 persona 的主要答案平均約占 96%，但逐次完全命中真人答案僅約 6.0%；15 位 persona 的眾數答案中，僅 1 位與真人一致。

這個探索性前測提醒我們：模型可能穩定地壓縮極端態度，或固定偏向某一答案。正式應用前，必須以未參與調整的樣本進行跨模型、out-of-sample 驗證。
